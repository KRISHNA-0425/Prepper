# Prepper AI — Standalone Linux Execution Worker Guide
## Zero-Docker, Zero-PostgreSQL, Zero-Redis Architecture

This guide details how to deploy the **Go-Judge** isolated execution worker on any free or low-cost Linux VPS (such as Oracle Cloud Always Free, Google Cloud Always Free `e2-micro`, or a dedicated host).

---

### 1. Requirements & Prerequisites
- **Operating System**: Ubuntu 20.04 / 22.04 / 24.04 LTS or Debian 11 / 12
- **Architecture**: AMD64 (`x86_64`) or ARM64 (`aarch64`)
- **Access**: Root / sudo access
- **Memory**: 1 GB RAM minimum (2 GB+ recommended for heavy concurrent Java compilations)
- **Zero Containers**: Runs directly as a native systemd binary service without Docker, PostgreSQL, or Redis.

---

### 2. 1-Step Automated Installation
Run the deployment script on your Linux server:

```bash
# Upload and run the installer
chmod +x deploy-go-judge-worker.sh
sudo ./deploy-go-judge-worker.sh
```

The script will automatically:
1. Detect your system CPU architecture (`amd64` vs `arm64`).
2. Install standard compilation and runtime packages (`build-essential`, `gcc`, `g++`, `python3`, `default-jdk-headless`, `nodejs`).
3. Download the official precompiled `go-judge` standalone binary from GitHub.
4. Generate a 256-bit cryptographic bearer token.
5. Create and start the `go-judge.service` systemd daemon.
6. Print the exact environment variables to paste into your Render dashboard.

---

### 3. Firewall & Security Configuration
To protect port 5050 from unauthenticated brute-force attacks:

```bash
# Allow SSH and Go-Judge port
sudo ufw allow 22/tcp
sudo ufw allow 5050/tcp
sudo ufw enable
```

Or for maximum security, place it behind a free **Cloudflare Tunnel (`cloudflared`)** so port 5050 is never exposed publicly to the internet, and all traffic from Render is end-to-end encrypted with HTTPS.

---

### 4. Connecting Render Web Service
In your Render Dashboard, add the environment variables generated by the worker script:

```ini
CODE_EXECUTION_ENABLED=true
CODE_EXECUTION_PROVIDER=go-judge
CODE_EXECUTION_URL=http://<YOUR-WORKER-PUBLIC-IP>:5050
CODE_EXECUTION_API_KEY=<GENERATED-SECRET-TOKEN>
CODE_EXECUTION_TIMEOUT=12000
MAX_CONCURRENT_EXECUTIONS=10
```
